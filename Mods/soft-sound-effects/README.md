# Soft Sound Effects and MP3 Audio Replacements

Soft Sound Effects contains gently filtered WAV effects derived from the
Episode 1 shareware data and is enabled by default. MP3 Audio Replacements
contains the alternate Episode 1 soundtrack and is disabled by default.
Toggle either mod from the launcher's Mods screen.
