# Soft Sound Effects and MP3 Audio Replacements

Soft Sound Effects contains gently filtered WAV effects derived from the
Episode 1 shareware data. The default **SFX** option is **Softened**.
The default **Soundtrack** option is **New Remixed**, which uses the bundled
MP3 tracks for Episode 1. Switch either option to **Original** in the
launcher's **Customise** menu.

Cosmo's music and sound effects remain © Apogee Software, Ltd. The mod files are separate from the MIT-licensed source code.
